# NixOS Hosts

Each subdirectory represents one NixOS computer. Its `configuration.nix` imports
the NixOS profiles and declares the Home Manager configuration for its users.
Its `hardware-configuration.nix` is unique to the computer and is normally
generated by the NixOS installer.

Add a host to `flake.nix` with `nixpkgs.lib.nixosSystem`, then apply it with:

```bash
sudo nixos-rebuild switch --flake .#host-name
```
