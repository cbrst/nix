## What this repository is

This repository is a [Nix flake](https://nixos.wiki/wiki/Flakes). `flake.nix`
pins every external dependency and exports a small set of named
configurations. Each configuration is assembled from the same building blocks:
a **host** selects **profiles**, profiles bundle **modules**, and modules own
one feature each, such as the shell, Neovim, audio, or the Niri compositor.

<CardGrid>
  <Card title="Two real machines" icon="laptop">

    Secure Boot. **Niflheim** is a Mac that receives the same development
    environment through standalone Home Manager.
  </Card>
  <Card title="Templates" icon="document">
    `example-nixos`, `example-user@generic-linux`, and `example-user@macbook`
    show how to reuse the profiles on a new machine.
  </Card>
  <Card title="One theme, everywhere" icon="seti:css">
    A shared theme family (Meowsoot or Kanagawa) and font set are rendered into
    the terminal, editors, browser, shell prompt, compositor, and boot loader.
  </Card>
  <Card title="Nix owns the toolchain" icon="seti:config">
    Editor plugins, language servers, formatters, debuggers, and Tree-sitter
    grammars are all declared in Nix. Nothing is downloaded at runtime.
  </Card>
</CardGrid>

## Exported configurations

| Output | Platform | What it builds |
| --- | --- | --- |
| `nixosConfigurations.asgard` | `x86_64-linux` | The Asgard workstation, including Home Manager for `cbrst` |
| `nixosConfigurations.example-nixos` | `x86_64-linux` | Template NixOS host with Home Manager for `example-user` |
| `homeConfigurations."cbrst@niflheim"` | `aarch64-darwin` | The Niflheim Mac user environment |
| `homeConfigurations."example-user@generic-linux"` | `x86_64-linux` | Template development environment for any Linux distribution |
| `homeConfigurations."example-user@macbook"` | `aarch64-darwin` | Template development and desktop environment for macOS |
