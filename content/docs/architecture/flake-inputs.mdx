---
title: Flake inputs and overlays
description: The external projects the flake pins, and the local package fixes applied on top of nixpkgs.
---

`flake.nix` pins every external dependency in `flake.lock`. Builds use exactly
these revisions until the lock file is updated deliberately.

## Inputs

| Input | Purpose |
| --- | --- |
| `nixpkgs` | `nixos-unstable`, the package set for every output |
| `home-manager` | User environment management; follows `nixpkgs` |
| `nur` | Nix User Repository, mainly for Firefox add-ons and a Sass language server |
| `noctalia`, `noctalia-greeter` | The Noctalia desktop shell and its login greeter |
| `affinity-nix` | Affinity creative applications, with its own binary cache |
| `brave-origin` | The upstream Brave browser build |
| `serena` | The Serena MCP server used by AI coding tools |
| `zshcs` | A Zsh language server for the editors |
| `rtk-src` | Source for RTK, built locally (not a flake) |

Inputs that are flakes and take `nixpkgs` follow the repository's `nixpkgs`, so
the whole configuration builds against one package set.

The flake's `nixConfig` adds the `cache.forall.systems` binary cache, which
serves the Affinity packages. Asgard also lists it in `nix.settings` so the
system's Nix daemon uses it.

## Local packages

[`packages/`](https://github.com/cbrst/nix/tree/main/packages) contains
derivations that nixpkgs does not provide:

- **RTK** (`packages/rtk`): "Rust Token Killer", which compresses command
  output for AI agents. It is built from the pinned `rtk-src` input. Its test
  suite is skipped because the crate denies warnings that only appear in the
  test build; the release binary builds normally.
- **set-noctalia-wallpaper** (`packages/set-noctalia-wallpaper`): a shell
  script that converts an image to the Noctalia wallpaper. The imv and Nautilus
  modules build the same derivation from it.
- **nixie** (`packages/nixie`): the gum-based flake management command,
  installed by the minimal profile (see
  [nixie](/modules/home/small-modules/#nixie)). Its `flake.nix` is a
  development sub-flake, not an output of the root flake.
- **Kanagawa GTK theme** (`packages/kanagawa-gtk-theme`): installed when the
  theme family is `kanagawa`.

## Overlays

`flake.nix` exports `overlays.typescript-language-server-pnpm-hash-fix`. The
pinned nixpkgs records a stale `pnpmDeps` hash for `typescript-language-server`,
so every build of it failed with a hash mismatch. The overlay pins the hash
that the fetch actually produces. It is applied in `configLib.mkHome` and should
be removed once nixpkgs is fixed upstream.

NixOS hosts add the NUR overlay through the desktop profile. The Affinity
overlay is not applied to any shared package set: the Affinity module imports a
separate nixpkgs pinned to `affinity-nix`'s own `nixpkgs` input, with the overlay
and `allowUnfree` applied only there, and takes `affinity-v3` from it. The
uncacheable Wine prefix is therefore rebuilt only when the `affinity-nix` input
changes, and `affinity-v3` may use different build inputs from the rest of the
system.
