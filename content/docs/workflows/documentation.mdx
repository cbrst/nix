This site is built with [Fumadocs](https://fumadocs.dev) on Next.js and
published to GitHub Pages. Its source lives on the separate
[`docs` branch](https://github.com/cbrst/nix/tree/docs), not on `main`.

## Keeping it current

Two GitHub Actions workflows keep the site in step with the configuration:

1. **Docs sync** (`.github/workflows/docs-sync.yml` on `main`) runs on every
   push to `main` that changes configuration, that is, anything outside
   `.github/` and `flake.lock`. It checks the `docs` branch out into `docs/`.
   Claude Code reads the commits since the last sync, which is recorded in
   `.last-sync` on the `docs` branch, including their messages and diffs. It
   checks them against the current source and revises the affected pages. The
   workflow builds the site, opens or updates a single `docs-sync` pull request
   against `docs`, and squash-merges it once the build succeeds.
2. **Docs deploy** (`.github/workflows/docs-deploy.yml` on `docs`) builds the
   site and publishes it to GitHub Pages. It runs on direct pushes to `docs`.
   Merges made with the workflow's token do not trigger it, so the sync
   workflow calls it explicitly after merging.

The pages describe the configuration as it is now; they are not a changelog.
The commit history remains the record of how it got there.

Because `.last-sync` only advances when a sync pull request is merged, a sync
that fails to build or merge is never lost. The next run covers every commit
since the last merged sync. The bot never merges into `main`, so it does not
move `main` underneath local work.

The sync agent's instructions are in
[`.github/docs-sync-prompt.md`](https://github.com/cbrst/nix/blob/main/.github/docs-sync-prompt.md).
It authenticates with a Claude Code OAuth token (`CLAUDE_CODE_OAUTH_TOKEN`),
so runs count against a Claude subscription instead of API billing.

## Editing by hand

Pages are MDX files in `content/docs/` on the `docs` branch. Each folder has a
`meta.json` that sets its sidebar title and page order. The "Open" menu on every
page links to its source on GitHub, and "Copy Markdown" copies the page for
pasting into an AI chat. Hand edits are fine; the sync agent revises pages in
place rather than regenerating them.

The site also publishes `llms.txt` and `llms-full.txt`, an index and a
full-text dump of every page for AI tools.

Edit in a separate workspace outside the `main` checkout, which ignores
`/docs/`. Fetch first, since the bot advances `docs@origin`.

## Building locally

```bash
jj workspace add ../nix-docs -r docs
cd ../nix-docs
nix shell nixpkgs#nodejs -c npm ci
nix shell nixpkgs#nodejs -c npm run dev     # live preview
nix shell nixpkgs#nodejs -c npm run build   # static export into out/
```
