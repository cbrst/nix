---
title: Home profiles
description: Bundles of Home Manager modules for user environments.
---

Home profiles live in
[`profiles/home/`](https://github.com/cbrst/nix/tree/main/profiles/home) and
group [Home Manager modules](/modules/home/shell/) by role. Profiles build
on each other so that every machine shares one base.

```text
minimal
└── development
desktop-base
├── desktop-linux
└── desktop-macos
gaming
```

## minimal

A small command-line environment for any user machine:
[shell](/modules/home/shell/), [SSH](/modules/home/small-modules/#ssh),
[version control](/modules/home/vcs/), and the
[1Password](/modules/home/small-modules/#1password) CLI and SSH agent.
Bitwarden is available as a drop-in alternative to 1Password but is not
imported.

## development

Everything in `minimal`, plus:

- [Neovim](/modules/home/neovim/) with its language servers, formatters, and
  debuggers.
- [VS Code](/modules/home/small-modules/#vs-code) (application only).
- [AI tooling](/modules/home/ai/): Claude Code, Serena, RTK, and agents.
- [direnv](/modules/home/small-modules/#direnv) with nix-direnv, and
  LazyDocker.
- Node.js, with the npm global prefix moved to `~/.local/share/npm` so global
  installs work without root, and its `bin` directory added to `PATH`.

## desktop-base

The portable desktop pieces that work on Linux and macOS: the
[Ghostty](/modules/home/ghostty/) terminal and the 0xProto and 0xPropo
fonts.

## desktop-linux

`desktop-base`, plus the Linux desktop applications:
[Niri](/modules/home/niri/) and [Noctalia](/modules/home/noctalia/)
configuration, [Firefox](/modules/home/firefox/),
[Nautilus extensions, imv, mpv, Affinity, Brave, Helium, Nextcloud, Sone, and
the Tailscale tray](/modules/home/desktop-apps/).

## desktop-macos

`desktop-base`, plus the [Karabiner-Elements](/modules/home/karabiner/)
configuration and Ice, a menu bar manager.

## gaming

[MangoHud](/modules/home/small-modules/#mangohud) with a toggle key, and
Prism Launcher for Minecraft. It complements the system-level
[gaming module](/modules/nixos/gaming/).
