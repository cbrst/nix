NixOS profiles live in
[`profiles/nixos/`](https://github.com/cbrst/nix/tree/main/profiles/nixos).

## desktop

A complete Wayland desktop. It allows unfree packages (needed for 1Password),
adds the NUR overlay, and imports:

| Module | Provides |
| --- | --- |
| [base](/modules/nixos/base/) | Flakes, garbage collection, Zsh, generation diffs |
| [network](/modules/nixos/network/) | DNS, firewall, Tailscale |
| [desktop modules](/modules/nixos/desktop/) | Niri, Noctalia and its greeter, PipeWire, fonts, GTK, Nautilus, multimedia, archives |
| [1Password](/modules/nixos/desktop/#1password) | The CLI and GUI with polkit integration |

## development

System-level development tools: [rootless Docker and JetBrains
IDEs](/modules/nixos/development/). Both Asgard and `example-nixos` import
it.
