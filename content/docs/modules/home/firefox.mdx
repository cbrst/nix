[`modules/home/firefox/`](https://github.com/cbrst/nix/tree/main/modules/home/firefox)
manages one default Firefox profile. It is part of the
[desktop-linux profile](/profiles/home/#desktop-linux).

## Settings

The profile restores the previous session on start-up, hides the bookmarks
toolbar, and enables tracking protection. The rest is grouped like the
[Betterfox](https://github.com/yokoffing/Betterfox) project it borrows from:

- **Fastfox:** larger font, canvas, and network caches, and more parallel
  connections.
- **Securefox:** downloads start in a temporary directory, Global Privacy
  Control is on, search suggestions and form autofill are off, and all
  telemetry, health reports, and coverage pings are disabled.
- **Smoothfox:** physics-based smooth scrolling with a faster wheel.

## Extensions

Extensions are installed from NUR and enabled automatically: Tridactyl,
uBlock Origin, Stylus, Tampermonkey, SponsorBlock, and Export Cookies. The
password-manager extension is added by whichever password-manager module is
imported, [1Password](/modules/home/small-modules/#1password) or Bitwarden,
so the browser module does not need to know which one is in use.

`ffmpeg` and `yt-dlp` are installed alongside.

## Tridactyl

Tridactyl provides Vim-style browsing. Its native messaging host is installed,
`~/.config/tridactyl/tridactylrc` is linked from the repository, and its theme
CSS is rendered from the shared palette. The rc enables smooth scrolling,
recognises German "next"/"previous" link text, adds `yf` to copy a link from a
hint, and removes bindings that get in the way. It also defines search URLs for
Amazon, DuckDuckGo, Modrinth, NZBFinder, Perplexity, the Wayback Machine, and
the Nix package and option searches. The developer searches are grouped
together: caniuse.com (`ciu`), GitHub (`github`), and the MDN Web Docs (`mdn`).

## Browser chrome

`userChrome.css` combines a theme rendered from both palettes (`theme.css`) with
layout rules (`userChrome.css`). Tab groups use the expanded accent colours.

### Auto-hiding navigation bar

The navigation bar is taken out of the toolbox layout, so the page starts
directly below the tab strip and never resizes. The bar is hidden by default and
appears as an overlay on top of the page when the pointer rests for 350 ms on
empty tab-strip space or the new-tab button. Hovering over tabs or tab groups
does not reveal it. It stays visible while hovered, focused, or while a panel or
menu anchored to it is open, and hides 250 ms after that.

The hidden state uses `clip-path` and opacity rather than `display` or
`visibility`, so pop-up panels and permission prompts still anchor to their
buttons, and a hidden bar cannot block clicks on the page. Customise mode,
full screen, and pop-up windows without a toolbar keep the stock layout.
