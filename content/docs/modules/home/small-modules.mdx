These modules are a single file each in
[`modules/home/`](https://github.com/cbrst/nix/tree/main/modules/home).

## 1Password

`1password.nix` (minimal profile) installs the `op` CLI, points `SSH_AUTH_SOCK`
and SSH's `IdentityAgent` at the 1Password agent socket, and adds the
1Password extension to Firefox when Firefox is enabled. The NixOS side installs
the desktop application (see [desktop modules](/modules/nixos/desktop/#1password)).

## Bitwarden

`bitwarden.nix` is a drop-in alternative to 1Password: it installs the desktop
app and CLI, uses the Bitwarden SSH agent socket, and adds the Bitwarden
Firefox extension. It is not imported by any profile; swap it for
`1password.nix` in the minimal profile to use it.

## SSH

`ssh.nix` (minimal profile) replaces Home Manager's default SSH configuration
with explicit defaults: no agent forwarding, no automatic key adding, no
compression. Every connection sends a keep-alive probe after 15 seconds of
idleness and gives up after three unanswered probes, so a dead link is noticed
in about 45 seconds. Personal host entries live in `~/.ssh/hosts`, which is
included but kept outside the repository.

It also installs the `mosh` client. Only the client is installed: a host still
needs `mosh-server` and open UDP ports 60000-61000 to accept connections.

## nixie

`nixie.nix` (minimal profile) installs `nixie`, a gum-based command for
day-to-day management of this flake. Without arguments it opens an interactive
menu; with a subcommand it runs that action directly.

| Command | Action |
| --- | --- |
| `status` | Checkout state, running generations, and input ages |
| `update [INPUT…] [--dry-run]` | Update all or selected flake inputs |
| `rebuild [TARGET] [ACTION]` | Build, show a package diff, confirm, activate |
| `diff` | Build without activating and compare with the running generation |
| `clean` | Delete old generations and collect garbage (`--keep N`, `--older-than 14d`, `--gc-only`, `--optimise`, `--dry-run`) |
| `generations`, `rollback [GEN]` | List or switch system generations (NixOS only) |
| `check` | `nix flake check --no-build` |
| `edit` | Open the flake in `$VISUAL` or `$EDITOR` |

`rebuild` targets are `all` (default), `home`, `nvim`, and `nvim-lite`; actions
are `switch` (default), `boot`, `test`, `build`, and `dry`. Rebuilds show a
package diff with nvd and ask for confirmation before activating. Without a
TTY, `--yes` is required for any action that would otherwise prompt. Before
building, nixie warns about files that jj tracks but Git's index does not,
because a Git-backed flake evaluation cannot see them.

The flake checkout defaults to `/etc/nix-config` on Linux and `~/nix-config` on
macOS. `NIXIE_FLAKE` overrides the path and `NIXIE_HOST` the host name;
`NO_COLOR` gives plain output.

The command is a `writeShellApplication` built from
[`packages/nixie`](https://github.com/cbrst/nix/tree/main/packages/nixie).
Its runtime tools are pinned in the package, but `nix` and `nixos-rebuild` come
from the running system so they match the installed daemon and NixOS release.
`packages/nixie/flake.nix` is a development sub-flake: its default dev shell
provides `nixie-dev`, which runs the working-tree `nixie.sh` without a rebuild.
Its nixpkgs input is locked to the root flake's revision.

## direnv

`direnv.nix` (development profile) enables direnv with Zsh integration and
nix-direnv, which caches `use flake` environments.

## LazyDocker

`lazydocker.nix` (development profile) installs the Docker terminal UI. It
pairs with [rootless Docker](/modules/nixos/development/) on NixOS.

## VS Code

`code/` (development profile) installs VS Code but deliberately does not manage
its default profile, so extensions and settings are configured in the
application. The previous declarative profile, with extensions, themes from the
shared settings, and font settings, is kept as a commented reference for a
future re-enable.

## Fonts

`fonts.nix` (desktop-base profile) installs the 0xProto and 0xPropo families
named in the shared [settings](/architecture/settings-and-themes/).

## MangoHud

`mangohud.nix` (gaming profile) enables the MangoHud performance overlay with
preset 3, toggled with `Right Shift+F12`.

## Prism Launcher

`prismlauncher.nix` (gaming profile) installs the Minecraft launcher.

## Foot

`foot/` configures the Foot terminal. Its `colors-light` and `colors-dark`
sections are generated from the active theme family's palette. No profile
imports it; Ghostty is the terminal in use.
