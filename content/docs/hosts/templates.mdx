---
title: Template hosts
description: The example NixOS, Linux, and macOS hosts used as starting points.
---

The template hosts are complete, buildable configurations that use the same
profiles as the real machines. They exist to keep the reusable parts honest
and to give a new machine a starting point. See
[Using the templates](/getting-started/adapting/) for how to adapt them.

## example-nixos

[`hosts/nixos/example-nixos/`](https://github.com/cbrst/nix/tree/main/hosts/nixos/example-nixos)
is a NixOS host for `example-user`. It imports the NixOS desktop and
development profiles, boots with GRUB on a placeholder `/dev/sda`, and embeds
Home Manager with the development profile. Its hardware configuration is a
placeholder, so it must not be applied unchanged.

## example-user@generic-linux

[`hosts/home/generic-linux.nix`](https://github.com/cbrst/nix/blob/main/hosts/home/generic-linux.nix)
configures a user on any `x86_64-linux` distribution with the development
profile only: shell, version control, editors, and AI tooling, without a
desktop.

## example-user@macbook

[`hosts/home/macbook.nix`](https://github.com/cbrst/nix/blob/main/hosts/home/macbook.nix)
configures a user on `aarch64-darwin` with the development and desktop-base
profiles, plus `terminal-notifier`.
